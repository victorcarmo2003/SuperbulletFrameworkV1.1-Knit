## Project Structure & Stack

**SuperbulletFrameworkV1-Knit** is a [Rojo](https://rojo.space/) project laid out feature-based, with [Rogen](https://github.com/LDGerrits/rogen) generating `default.project.json` automatically from `framework/src/**` (no manual `$path`):

```
framework/src/
├── Bootstrap/{client,server}/                 << loaders — scan for *Service/*Controller/*Behavior modules and require() them
├── Profile/{client,server,shared}/            << ProfileService (data), DataController, ProfileTemplate
├── SuperbulletLogger/{client,server,shared}/  << Studio-only debug bridge to the SuperbulletAI desktop app
├── Interface/client/                          << Vide + UI Labs UI layer (Elements/, Story/)
├── Behaviors/{client,server}/                 << CollectionService tag-bound components
└── Mixins/{shared,client,server}/             << shared traits consumed explicitly by Behaviors
```

Each feature has `client/` (→ `StarterPlayerScripts`), `server/` (→ `ServerScriptService`) and/or `shared/` (→ `ReplicatedStorage`); Rogen routes each one automatically by folder name.

### Two component patterns coexist

1. **Service/Controller** (`Superbullet.CreateService` / `Superbullet.CreateController`) — one instance per system. `Instance = script` enables autoloading of `Components/{Accessor,Mutator,Others}` (read/write/misc separation once a system grows past ~300 lines).
2. **Behaviors/Mixins** — tag-bound components via [`sleitnick/component`](https://github.com/Sleitnick/RbxUtil) + `CollectionService`: one instance per tagged `Instance` in the world (any number of them), not per system. A `Behavior` (`*Behavior.lua`) implements `Construct`/`Start`/`Stop`; code shared between unrelated Behaviors lives in an explicitly-called `Mixin` (never automatic method merging). Great fit for placeable/taggable gameplay objects (pickups, doors, damage zones); Service/Controller stays for the "one per game" systems.

### Stack

- Luau / Roblox, Rojo project generated by Rogen.
- Knit modified, published as an external Wally package — [`victorcarmo2003/superbullet-knit`](https://github.com/victorcarmo2003/superbullet-knit) (`framework/Packages/Superbullet.lua` re-exports it; no more hand-vendored fork).
- [`sleitnick/component`](https://github.com/Sleitnick/RbxUtil) for the Behaviors/Mixins tag-bound pattern.
- UI: [Vide](https://github.com/centau/vide) (reactive) + the UI Labs pattern (Studio storybook), under `Interface/client/`.
- Player data: ProfileService/ProfileStore (loleris/MAD STUDIO).
